SITE SURPRESA DA GIULIA 💜

Abra index.html no navegador.

Arquivos:
- index.html = estrutura
- style.css = visual
- script.js = animações/interações
- fotos/foto1.jpeg e foto2.jpeg = fotos enviadas

Para editar:
1. Abra a pasta no VS Code.
2. Edite os textos do index.html.
3. Troque as fotos dentro de fotos/ mantendo os nomes ou altere os caminhos no HTML.
4. Abra index.html no navegador.

O site não precisa de servidor para funcionar. A fonte é carregada da internet; o restante funciona localmente.
